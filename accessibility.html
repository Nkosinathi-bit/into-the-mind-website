Accessibility Features

Features and limitations of this academic HTML, CSS and JavaScript project.

Features in the Source

Page Structure

Semantic landmarks, headings, descriptive image text and labels for form controls.

Keyboard Navigation

Skip links, native links and visible focus styles support navigation without a mouse.

Responsive Layouts

CSS Grid, Flexbox and media queries adapt page layouts to different viewport sizes.

Reduced Motion

A reduced-motion media query adjusts animation and transition behaviour.

Verification Scope

Accessibility is a continuing learning goal for this project. Independent conformance assessment and assistive-technology testing remain future work.

Current Limitations

  • Content is currently presented in English.
  • Article search, saved articles, challenge tracking, the timer and message previews need JavaScript. Articles, navigation and accordions remain available without it.
  • The contact page previews and downloads drafts; it does not send messages. Reading plans replace the inactive newsletter signups.
  • Saved article choices and challenge progress stay in this browser. If browser storage is unavailable, changes last for the current page visit only.
  • Screen-reader and contrast testing need further review.
